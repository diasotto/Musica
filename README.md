 Rec Album

**Aluno:** Otto Dias  
**Curso:** Informática 3º ano  
**Unidade curricular:** Codificar aplicações para dispositivos móveis

 Projeto

O Rec Album é uma aplicação para guardar e organizar álbuns de música. É possível adicionar álbuns, músicas, capas e favoritos. Os dados ficam guardados localmente no dispositivo.

 Tecnologias

Vue 3, TypeScript, Ionic, Vite e Capacitor.

 Como rodar

Instalar as dependências e iniciar no navegador:

bash
npm install
npm run dev


Para abrir no Android Studio:

bash
npm run build
npx cap sync android
npx cap open android


No Android Studio, escolha um emulador e clique em **Run**.
